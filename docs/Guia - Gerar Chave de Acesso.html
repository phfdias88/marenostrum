Gerar Chave de Acesso

Passo a passo para ligar o MareNostrum a uma planilha, a um BI ou a outro programa.

O que é isso

Uma chave é como um crachá de visitante para programas: permite que outro sistema leia os dados do MareNostrum sem precisar da sua senha.

Ela só lê. Não cria, não altera e não apaga nada — mesmo que alguém tente. E dá para cancelar quando quiser, sem mexer no seu login.

Quem pode gerar: apenas o administrador e o Daniel. O botão nem aparece para as outras contas.

Como gerar

  1. Entre no sistema

    Acesse marenostrumconsult.com.br/sistema com o seu e-mail e senha de sempre.

  2. Abra o Painel Mare Nostrum

    É o painel que você já usa para ver os clientes e criar contas de cortesia. Role até o fim da página — o quadro “Chaves de acesso aos dados” fica embaixo da lista de clientes.

  3. Preencha e clique em Gerar chave

    Escreva para que serve a chave. Esse nome é só para você identificar depois, na hora de cancelar.

  4. Copie a chave na hora

    Ela aparece uma única vez, num quadro destacado, com um botão de copiar.

    Guarde no seu gerenciador de senhas. Depois de fechar, nem nós conseguimos recuperá-la — só cancelar e gerar outra, o que leva dez segundos.

Entregando a chave a quem vai usar

Quem for programar a integração precisa de duas coisas: a chave e o endereço do sistema. É só passar isto:

Endereçomarenostrumconsult.com.br/sistema/api/v1
CabeçalhoX-API-Key: a-chave-gerada
Manualmarenostrumconsult.com.br/sistema/api/docs

O manual é interativo: quem estiver programando vê a lista completa do que dá para puxar e testa cada consulta ali mesmo, no navegador.

Cancelar uma chave

No mesmo quadro do painel, cada chave tem Cancelar ao lado. O corte é imediato: quem estiver usando aquela chave perde o acesso no mesmo instante, e nenhuma outra chave é afetada.

A lista também mostra quantas vezes cada chave foi usada — serve para descobrir quais integrações ainda estão vivas antes de fazer faxina.

Cuidados

Trate a chave como uma senha. Ela lê os dados das campanhas, incluindo informação pessoal de eleitores.

Não mande por WhatsApp nem deixe em planilha compartilhada. Se desconfiar que vazou, cancele — leva um clique e vale na hora.

Prefira uma chave por finalidade: uma para o BI, outra para o site, outra para cada parceiro. Assim dá para cortar uma sem derrubar as demais, e fica claro quem estava usando o quê.
